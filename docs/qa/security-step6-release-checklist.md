# Schritt 6 – verbindliche Freigabecheckliste (alle Punkte OFFEN)

Keine Ausführungsfreigabe. Der ausführliche Ablauf G0–G8 aus `security-step5-migration-runbook.md` bleibt erhalten. Die heutigen manuellen Befunde schließen nur den RLS-Status und vier effektive Rechte für zehn Tabellen, **keines** der nachfolgenden Freigabegates. Für jede Zeile sind Verantwortlicher, Datum, Artefakt-SHA und unabhängiges Review nachzutragen. Keine Checkbox wird durch einen allgemeinen grünen CI-Lauf automatisch geschlossen.
